## Ausführen

Voraussetzung: ein JDK (z. B. Java 21 oder neuer).

```powershell
cd Tag05_2026-11-05\BierTrinken
javac -encoding UTF-8 *.java
java BierTrinken
```

Alle Dateien sind UTF-8-kodiert. Klassen mit Umlauten im Namen (z. B. `Hochzählen`) brauchen deshalb `-encoding UTF-8`.
